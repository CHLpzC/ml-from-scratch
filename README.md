# ml-from-scratch

This repository is dedicated to mastering the mathematical foundations of Machine Learning Engineering by building algorithms from scratch. 

Instead of using high-level libraries like PyTorch or Scikit-Learn, I am translating core concepts directly from my textbooks (*Strang's Linear Algebra*, *Larson's Calculus*, and *Mathematics for Machine Learning*) into clean, raw Python and NumPy code.

## 🎯 Current Approach
* **Code Over Libraries**: Writing algorithms manually to understand the underlying calculus and matrix transformations.
* **Vectorization**: Leveraging NumPy arrays to handle data efficiently without slow, nested loops.
* **Systematic Progress**: I add new files and modules to this repository organically as I progress through my math and AI curriculum.

## 📁 Repository Structure
* `/foundations/` — Core mathematical utilities, matrix operations, and helper scripts.
* `/models/` — Machine learning algorithms built step-by-step.
